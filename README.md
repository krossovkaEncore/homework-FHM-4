# homework-FHM-4

## 1. Комбинаторный расчёт

Четырёхзначный PIN-код состоит из цифр от 0 до 9. Цифра `0` в начале разрешена, поэтому каждая из четырёх позиций имеет 10 вариантов.

Общее количество PIN-кодов:

\\[ N = 10^4 = 10000 \\]

1\. Коды, в которых все цифры одинаковые

Это коды `0000`, `1111`, …, `9999`. Всего таких кодов:

\\[ N_1 = 10 \\]

2\. Коды, в которых цифры идут строго по возрастанию подряд

Всего таких кодов:

\\[ N_2 = 7 \\]

Эти две группы не пересекаются, поэтому количество запрещённых PIN-кодов:

\\[ N\_{\text{запрещённых}} = 10 + 7 = 17 \\]

Количество допустимых PIN-кодов:

\\[ N\_{\text{допустимых}} = 10000 - 17 = 9983 \\]

Ответ: отсекается 17 запрещённых PIN-кодов, остаётся 9983 допустимых.
